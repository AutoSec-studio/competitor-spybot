## 🚀 Quickstart (30 Seconds)

### 1. Install Requirements
```bash
pip install -r requirements.txt
```

### 2. Configure Environment
```bash
cp .env.example .env
```
Edit `.env` with your store endpoint and credentials.

### 3. Launch
```bash
python main_lite.py
```
